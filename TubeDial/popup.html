Framerate limit

Heads-up: this one does hide versions. YouTube has no framerate choice, so the only way is to hide the smoother versions (the ⚙ menu then shows “1080p” instead of “1080p60”). Leave it on Any to keep everything. If a video has nothing that low, its lowest is used, so it always plays. You can change it for one video under Now → This video only.
